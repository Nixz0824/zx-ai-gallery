# ZHANG XIN

个人 AI 图像与视频档案。页面本身就是放映，文字只作旁注。横竖构图都会完整露出，周围用同一画面做氛围铺底。

## 打开

日常看作品、给别人看：直接打开 https://nixz0824.github.io/zx-ai-gallery/  
不需要开这个对话，也不需要开 Python。

本机上传并写入文件夹：双击 `打开本地页.bat`，或自己运行：

```bash
cd 网页/nix-archive
python server.py
```

然后浏览器打开 http://127.0.0.1:8765

也可以直接打开 `index.html`。不经过 `server.py`、也没在「发布设置」里填 GitHub 令牌时，上传只留在当前浏览器，访客看不到。

## 使用

- 顶栏切换 **图像 / 视频**
- 顶栏 **中 / EN** 切换界面语言
- 左右键或两侧空白切换作品
- 点爱心记录喜欢（存在本机）
- 点 **浏览** 再输入 GitHub 账户名进入本人模式。答对后可上传、编辑、删除、导出清单
- 有参考图的作品会出现 **参考**。点开后成品和参考并排对照，多张参考可点缩略图切换。键盘 `R` 也可开关

演示用静帧和短片可在本人模式删除，再换成你自己的作品。

## 上传字段

1. 图或视频文件
2. 模型 / 平台标签
3. 有无参考图。若有，可一次加入多张
4. 提示词

写入磁盘时，成品进 `media/images` 或 `media/videos`，参考图进 `media/refs`，条目进 `data/works.json`。

## 让别人看到最新作品

顺序可以是「先令牌后上传」，也可以「先上传后令牌」。

1. 打开本人模式，点 **发布设置**
2. 到 GitHub 生成 Fine-grained 或 classic 令牌，给这个仓库勾选 **Contents: Read and write**（classic 则勾 `repo`）
3. 把令牌贴进去，点 **保存并补发**。页面会检查令牌，并把这个浏览器里还没上线的作品写进仓库
4. 之后再上传：点「收入档案」时会同时写入 GitHub。右上角会写明「已与线上同步」或「本机还有 N 件未上线」
5. 大约一分钟后刷新 https://nixz0824.github.io/zx-ai-gallery/ 即可看到

没保存令牌时，上传只留在当前浏览器，Edge 和别人都看不到。令牌保存在这个浏览器的本地存储里，关掉标签也不会丢；点「清除」才会删掉。

也可以继续用 `git add` 后推送到仓库。

## 点赞

爱心旁边的数字是所有访客共用的。同一个人在同一浏览器里只能给一件作品计一次。本人模式里的 **点赞** 会列出每件作品当前的总数。
